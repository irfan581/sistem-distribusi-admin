Kebijakan Privasi Driver TM

Berlaku sejak 16 Oktober 2026

Driver TM adalah aplikasi internal untuk sopir pengiriman CV Tani Makmur Sejahtera (Tani Makmur), Jl. Contoh Raya No. 1, Kabupaten Madiun, Jawa Timur 60000. Aplikasi ini hanya dapat dipakai oleh sopir yang akunnya dibuat oleh kantor. Halaman ini menjelaskan data apa yang dikumpulkan aplikasi, untuk apa, dan bagaimana data itu dijaga.

Data yang dikumpulkan

  • Data akun. Kode sopir dan kata sandi saat masuk. Nama, nomor telepon, dan kendaraan sopir dicatat oleh kantor, lalu ditampilkan di aplikasi. Kata sandi disimpan di server dalam bentuk acak (hash), bukan teks asli.
  • Foto bukti bongkar dan catatan. Foto yang diambil sopir sebagai bukti barang sudah diturunkan di toko tujuan, beserta catatan yang ditulis sopir.
  • Lokasi. Koordinat GPS diambil hanya saat sopir memotret bukti bongkar atau melaporkan status tujuan, untuk menunjukkan di mana bukti itu dibuat. Aplikasi juga mencatat apakah lokasi berasal dari aplikasi pemalsu lokasi. Lokasi tidak dilacak terus-menerus dan tidak diambil di latar belakang. Bila izin lokasi tidak diberikan atau GPS gagal, laporan tetap terkirim tanpa koordinat.
  • Data perangkat. Pengenal perangkat untuk memastikan satu akun dipakai di satu HP, dan token notifikasi untuk mengirim pemberitahuan muatan baru.

Untuk apa data dipakai

  • Memberi tahu sopir tentang muatan dan tujuan pengiriman.
  • Mencatat bukti bahwa barang sudah diterima di setiap tujuan.
  • Menjaga keamanan akun.

Data tidak dipakai untuk iklan dan tidak dijual.

Pihak lain yang terlibat

Data disimpan di server yang dikelola kantor. Untuk mengirim notifikasi ke HP, aplikasi memakai layanan Firebase Cloud Messaging dari Google, yang menerima token notifikasi perangkat. Data tidak dibagikan kepada pihak lain, kecuali bila diwajibkan oleh hukum.

Keamanan

Semua data dikirim melalui koneksi terenkripsi (HTTPS). Sesi masuk disimpan di penyimpanan aman milik sistem Android di HP sopir. Hanya admin kantor yang berwenang yang dapat melihat data pengiriman di panel admin.

Berapa lama data disimpan

Data disimpan selama diperlukan untuk keperluan operasional dan pencatatan pengiriman perusahaan.

Hak sopir

Sopir dapat meminta salinan, perbaikan, atau penghapusan datanya dengan menghubungi kantor. Cara meminta penghapusan akun dijelaskan di Hapus Akun Driver TM. Akun dapat dinonaktifkan oleh kantor kapan saja, dan sesi masuk di HP ikut berakhir.

Usia pengguna

Aplikasi ini ditujukan untuk sopir dewasa yang bekerja untuk Tani Makmur, bukan untuk anak-anak.

Perubahan kebijakan
